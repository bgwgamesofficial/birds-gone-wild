Install Birds Gone Wild

Free to play. Installs in four taps and works offline.

▶ Play Birds Gone Wild
https://bgwgamesofficial.github.io/birds-gone-wild/

Android phone or tablet

  1. Open the game link above, tap the ⋮ menu (top right), then tap Install and create shortcut.

    In Chrome this is called Install app or Add to Home screen.

  2. Tap Install.

    Choose Install, not "Create shortcut". Install gives you a real app that opens full-screen and works offline.

  3. In the Install app box, tap Install.

  4. Tap Add to put Birds Gone Wild on your home screen. Done, tap the icon to play!

    You can also press and hold the icon to drag it where you want it.

Good to know

  • Opened the link inside Facebook, Messenger or TikTok? Tap the ⋮ menu and choose Open in browser (Chrome, Brave or Samsung Internet) first. Apps' built-in browsers often can't install games.
  • Updates are automatic. The game updates itself whenever you open it with internet. The version number is shown under the Start button.
  • iPhone or iPad: open the link in Safari, tap Share, then Add to Home Screen.
  • Computer: open the link in Chrome or Edge and click the install icon in the address bar.
